# Kelas Kreator

Kelas daring gratis untuk kreator konten Indonesia, program Pantau360 bersama Ekraf. Enam modul strategi konten, dari riset audiens sampai kerja sama brand.

Situs statis tanpa build step, disajikan lewat GitHub Pages dari branch `main`.

- `index.html`: halaman depan
- `kurikulum.html`: daftar modul dan pelajaran
- `modul/1.html` sampai `modul/6.html`: isi tiap modul
- `style.css`, `progress.js`: gaya dan penanda progres (localStorage, tanpa server)
- `assets/`: foto sampul

Palet mengikuti identitas Ekraf 2024: biru langit `#6fb6e2` dan abu gelap `#2c2c2e`.
